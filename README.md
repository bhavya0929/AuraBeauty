# AuraBeauty – Beauty & Skincare E-Commerce Website

**Where Beauty Meets Confidence**

AuraBeauty is a responsive front-end e-commerce website for beauty and skincare products, developed to demonstrate my skills in HTML, CSS, and JavaScript.

## About the Project

AuraBeauty provides a simple and user-friendly shopping experience, allowing users to explore beauty products and interact with shopping features through a clean, attractive interface.

## Features

* Responsive website design
* Beauty and skincare product listings
* Product categories and navigation
* Add to Cart functionality
* Wishlist functionality
* Login and registration pages
* Contact page
* Interactive user interface

## Technologies Used

* HTML5
* CSS3
* JavaScript

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser to explore the website.
